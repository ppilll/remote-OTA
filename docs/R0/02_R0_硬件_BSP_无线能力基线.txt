2. 曾发现并修复的问题
旧 rootfs 中的 8733bu.ko / rtk_btusb.ko 是按 Linux 5.10.160 编译，而运行 kernel 为 5.10.209，导致 version magic 不匹配。重新用同一 SDK 构建 Buildroot 后，两个模块 vermagic 均与运行内核一致。
后续发布纪律：kernel、vendor kernel modules、Buildroot rootfs 必须作为同一个 release baseline 构建与归档；禁止“只换 kernel、不更新依赖模块”的非可复现组合。

5. RTC / 时间基线
RTC 设备与驱动已存在（/dev/rtc0，pcf8563-compatible），但当前纽扣电池低电压，hwclock 无法得到可信时间。该问题已确认是硬件耗材问题，不再作为 R0 blocker。
状态	处理
当前	RTC low voltage；system time 可能回到 1970
关闭动作	更换 CR1220/兼容电池；date -s；hwclock -w；断电后验证 hwclock 继续前进
强制截止	HTTPS/TLS certificate validation 之前必须关闭
